# 斗地主实验报告

## 这个实验想说明什么

数独和 21 点都是一个人做决定，斗地主不一样：**两个人一边**，而且互相看不到牌。
所以它能回答一个数独回答不了的问题——**把"团队意识"写进策略里，到底值多少？**

玩法上也更接近真实场景：两家农民共享输赢，要不要帮队友、什么时候不能抢
队友的牌，这些都是"策略知识"而不是"算术题"。上游马里奥项目的思路就是把
这类该算的东西留在代码里、把需要感觉的部分交给模型；这个实验就是量一量
其中"团队规则"这一条的贡献。

## 具体测了两件事

1. **基线**：在参考策略下，先手、多三张牌的地主，和两家人家，谁赢得多？
   引擎撑不撑得住完整对局（每步都校验 54 张牌不重不漏）？
2. **配合的价值**：策略里有一条"农民不压队友的强牌"的规则（队友打出大牌、
   或队友快赢时让行）。把这条规则拿掉，农民胜率掉多少？

## 实验怎么做的

引擎用 `doudizhu_game.py`：确定性发牌（同一个种子发同一副牌）、10 种牌型、
压制规则齐全，每走一步都做 54 张牌的分区校验。

参考策略：领出时先卸大组合；跟牌时用刚好压得住的最小牌；炸弹只在危险时刻
用（对手只剩两张牌以内，或桌面牌已经到 A）。

两组对照，同样的 40 个种子各打 40 局：

- **有配合（现装版本）**：农民按上面的规则办事；
- **无配合（对照组）**：其他一模一样，只把"队友的牌不打"这条规则去掉——
  农民把队友也当对手，见大就压。

跑法：

```bash
python3 experiment.py
```

输出如下：

```
组别                    地主胜   农民胜   平均步数   平均炸弹数
有配合（现装）            22%      78%      60.9       0.12
无配合（对照组）           30%      70%      59.4       0.15
```

## 结果说明

### 基线：农民明显占优（78%）

地主虽然先出牌、还多拿三张底牌，但"两家农民共享输赢"这个结构本身就更有利
——一家出错另一家能兜。参考策略没有博弈论意义上的最优性，但 22% vs 78%
这个分布说明两边都有赢面，牌局是有来有回的，适合观战。

### "队友的牌不打"这一条值 8 个百分点

拿掉这条规则，农民胜率从 78% 掉到 70%，地主胜率相应从 22% 涨到 30%。

为什么？不配合的时候，农民会用大牌去压队友的小牌。这做了两件坏事：
火力本可以对着地主，结果消耗在队友身上；而且让地主多获得一次出牌机会。

**8 个百分点就是这一条团队规则的净贡献。** 这种"一条规则值多少胜率"的
量法很有用——以后给模型写策略时，每条规则单独 A/B 一下，就知道哪些知识
真的在起作用。

### 对真 Jev 的预期

真 Jev 拿到的信息和本地裁判完全一样（自己的牌、别家剩几张、桌面出什么），
我们的问题文本里也明确写了"队友的牌不要压"这条策略。它到底听不听、什么
时候该不听（比如自己快赢了该抢牌），恰好是这套环境能直接看出来的行为——
`make_record` 里的 gold 就是按配合版策略算的，偏离了多少一算就知道。

## 结论

1. 引擎完整可用：40 局自动对局全部通过校验，牌型、压制、胜负判定都正常；
2. 团队规则可以逐条定价：配合规则值 8 个百分点农民胜率；
3. 下一步：用 `--judge jev` 跑真模型，统计它"违反配合规则的频率"，就能看出
   它的团队意识有多少。

完整数据在 `artifacts/experiment_cooperation.json`。

## 附：Jev 扮演什么角色、花多少钱、要等多久

### Jev 在这个实验里干什么

每一轮回答一个问题：从全部合法出牌里选一个（一局大约 60 轮，每轮 50+ 个候选）。我们负责算清楚哪些牌合法、哪些能压过桌面，它负责挑。**它看不到另外两家的手牌**，和人类玩家一样。

### 每次推理的请求规模与费用（实测）

- 请求体积：**6537 字节**（紧凑 JSON，含 自己的手牌、桌面牌型、56 个候选动作各自的说明）
- 折合输入 token：约 **1,634**（按 4 字符约等于 1 token 估算，实际以 API 返回的
  `usage.input_tokens` 为准）
- 输出：只是一个选择加概率分布，约 20-60 token，**官方对输出免费**
- 定价（官方文档 `models.md`，2026-09）：输入 **$0.042 / 100 万 token**，输出 $0
- **单次推理成本：约 $0.00007**

### 响应时间

- 本地替身实测：0.02ms（50 次采样中位数）
- 真 Jev 参考：JevHarness 公开数据 median 259-269ms（Vercel 网关）
