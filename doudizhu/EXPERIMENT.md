# 斗地主实验报告

## 1. 实验意义

斗地主是"不完美信息 + 非对称队伍"的最小牌类试验台：地主 20 张对两农民 17+17，
信息不可见（模型只看到公开事实：自己的手牌、别家张数、桌面牌型），且两农民存在
**队伍配合**维度。它回答的是数独/21点回答不了的问题：**当最优策略不可计算时，
"团队行为规则"写进策略里值多少？** 这也是对上游 typesafe-mario 思路的反向验证——
上游把精确时序算术留在代码里、把判断交给模型；斗地主实验测量的是其中"队伍规则"
这一类代码知识的贡献。

## 2. 说明的问题

1. **基线平衡**：在参考策略下，先手+多牌的地主与两农民的胜率分布是什么？
   引擎的合法性校验能否支撑完整自对弈？
2. **农民配合的价值**：策略中的配合规则（农民不压制队友的强牌：rank ≥ J 或队友
   剩牌 ≤4 时让行）对农民胜率贡献多大？
3. **可玩性**：出牌节奏、炸弹/倍率出现频率是否支撑一个"有趣"的观战页面？

## 3. 实验过程

引擎：`doudizhu_game.py`——SplitMix64 确定性发牌、10 种牌型生成、压制规则、
54 张分区校验（每步后全量验证）。参考策略：领出卸最大组合、跟牌最小压制、
炸弹只在危险时（对手 ≤2 张或桌面 rank ≥ A）出手。

双臂对照，同种子（seeds 1–40）各 40 局：

- `cooperative (shipped)`——完整参考策略（含农民配合）；
- `no_cooperation (ablated)`——其余不变，农民把队友的牌当作对手的牌对待。

复现命令：

```bash
python3 experiment.py
```

关键过程输出：

```
arm                     landlord win  peasant win   plays   bombs
cooperative (shipped)         22%         78%    60.9    0.12
no_cooperation (ablated)        30%         70%    59.4    0.15
```

可视化服务实测（`serve_doudizhu.py`）：连续自动对局中观察到完整的"领出→压制→
两 pass 回到领出者"循环、三带二/顺子/连对等组合的自然出现、炸弹倍率翻倍的
震屏特效触发。

## 4. 实验结果说明

### 基线：农民胜率显著占优（78%）

地主的先手与 3 张底牌优势在本策略集下**不足以**抵消"两家农民共享胜负"的结构优势。
这与人类经验一致（配合好的两家农民难打），说明参考策略虽然没有博弈论最优性，
但已经落在"有来有回"的可玩区间——地主 22% 的胜率给双方都留了赢面。

### 农民配合规则价值 8 个百分点

去掉配合规则后农民胜率 78% → 70%，地主胜率相应上升。机制：不配合时农民互相
压制队友的强牌（用大牌压队友的小 K），消耗本可打向地主的火力，且让地主获得
额外出牌轮次。8 个百分点是**单条策略规则的净贡献**——这类"一条规则值多少胜率"
的度量正是把判定模型接入复杂游戏时 harness 设计所需要的标尺。

### 对接真实 Jev 的预期

真 Jev 拿到的是同样的公开事实 + 每动作 criterion（含"作为农民不压制队友"的
instructions 策略陈述）。它是否遵守队伍规则、何时决定违反（如自己快赢时抢队友
的牌），恰好是这套 harness 能直接观测的行为——`make_record` 的 gold（配合版
参考策略）就是偏离度量 的基准线。

## 5. 结论与后续

1. 引擎可支撑完整自对弈与长期自动对局，合法性校验无一失败；
2. 配合规则价值约 8 个百分点农民胜率——策略规则可以被逐条定价；
3. 后续：把 `serve_doudizhu.py --judge jev` 跑出的实际出牌序列与 gold 对齐，
   统计"违反配合规则的频率 × 局势"，即可度量真 Jev 的团队意识。
