# 数独实验报告

## 1. 实验意义

数独是"结构化约束下的单步判定"的最小试验台：每一步 judge 只需回答"这个格子填几"，
答案有唯一真值（唯一解可程序化判定），且判断材料可以被 harness 精确控制——发布多少
约束事实、发布什么形式，完全由实验者决定。这使它成为测量**「事实发布质量 → 模糊判定
准确率」**这条 JevHarness 核心命题的最干净环境：没有物理引擎噪声、没有延迟耦合、
错误可以立即归因到具体某一步。

## 2. 说明的问题

1. **难度可调控性**：空格数（40/45/50/55）能否作为可控的难度旋钮，产生有区分度的
   评测区间？
2. **约束事实的价值**：一个"读约束做推理"的裁判（naked/hidden single）是否比一个
   "拿到同样候选却不懂语义"的随机裁判更强？
3. **推理的覆盖边界**：约束推理（naked single / hidden single）在什么难度下不再
   足够？失败以什么形式出现？

## 3. 实验过程

环境：`sudoku_game.py`（SplitMix64 确定性生成、唯一解校验、MRV 选格）。
裁判两臂，均**看不到 solution**：

- `local_constraint`——读发布的候选做 naked single → hidden single → 回退（取最小候选）；
- `random_candidate`——对同一份候选均匀随机（种子固定，可复现）。

网格：空格数 {40, 45, 50, 55} × 每格 10 局（seeds 10400…10559）。填错记 mistake，
3 错终局。复现命令：

```bash
python3 experiment.py
```

关键过程输出（每次错误后棋盘不写入，错误只在计数器上，因此失败可逐步归因）：

```
holes judge                win  mean fill  mean mistakes
    40 local_constraint    10/10      40.0          0.00
    40 random_candidate    10/10      40.0          0.00
    45 local_constraint     8/10      37.8          0.60
    45 random_candidate    10/10      45.0          0.30
    50 local_constraint     3/10      22.9          2.10
    50 random_candidate     5/10      30.5          1.80
    55 local_constraint     0/10       8.1          3.00
    55 random_candidate     3/10      22.6          2.70
```

## 4. 实验结果说明

### 难度旋钮成立

40 洞两臂全胜；55 洞全部崩坏（最好 3/10）。45–55 洞是有区分度的评测区间。
机制：40 洞时 MRV 选出的格子几乎总有唯一候选（naked single 必然出现）；
55 洞后大量格子需要真正的搜索，逐步累积到 3 次错误预算耗尽。

### 反直觉发现：随机裁判胜过约束推理裁判

45 洞：随机 10/10 vs 约束 8/10；55 洞：随机 3/10 vs 约束 **0/10**。
机制藏在错误预算与确定性回退的交互里：

- hidden single 本身是逻辑必然，永远不会填错；
- 但当它覆盖不到时，local 裁判回退到**恒猜最小候选**——同一格猜错后格子不落盘，
  下一拍 MRV 仍选同一格，local 再次猜同一个错答案，**三次预算耗在同一格上**；
- 随机裁判会换着试，三次预算内命中概率显著更高（单格候选 ≤4 时 1-(3/4)³ ≈ 58%+
  的试错期望）。

这是一个纯 harness 层的缺陷，不是约束推理的失败：**确定性回退 + 有限错误预算**
组合下，"每次给同一个错答案"比"随机错"差得多。

### 对接真实 Jev 的预期

真 Jev 读到的是同一份约束事实（含"IMPOSSIBLE"标注的 criteria），但它的回退不是
`cands[0]`——它有机会做层级推理（本报告裁判只做了两层）。评测命令
`python3 jev_sudoku.py --judge jev` 零改动可用；45–55 洞区间即为推荐测试档位。

## 5. 结论与后续

1. 难度旋钮成立，推荐 45–55 洞作为评测档位；
2. 约束事实有价值，但**错误预算下的回退策略同样重要**——修法明确：回退时排除
   本格已错数字（runner 把 mistake 历史发给裁判即可），预计 55 洞胜率显著回升；
3. hidden single 之上的推理（X-wing / 链式排除）是下一个裁判层级，可作为衡量
   真实模型推理深度的标尺。
