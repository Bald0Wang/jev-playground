# 21点实验报告

## 1. 实验意义

21点是"不完全信息 + 概率可精确计算"的标准试验台：荷官规则固定（所有 17 停）、
赔率明确（BJ 3:2）、最优近似策略（基本策略表）是公开知识。它回答的问题是：
**当 harness 把可计算的量（鞋组成、爆牌概率）预计算好发给模型时，一个遵守
基本策略的判定者与一个"合理但朴素"的判定者，长期收益差距有多大？**

这为"预计算事实的价值"提供一个有真值参照的度量——21点的期望值结构是几十年
研究所熟知的：任何策略都改变不了负期望，但好策略显著改变**生存时间与破产路径**。

## 2. 说明的问题

1. **引擎正确性**：确定性鞋（SplitMix64）、3:2 赔付、庄家规则、double 限制、
   自动重洗能否支撑大规模自对弈而无校验失败？
2. **策略差距**：基本策略（gold）与"模仿庄家"朴素策略（<17 必 hit、从不
   double）在生存轮数、资金路径、爆牌率上的差距有多大？
3. **预计算事实的呈现**：鞋组成 JSON、爆牌概率这些发布事实，是否足以让一个
   真实模型在不需要自己数牌的情况下做出基本策略级的判断？

## 3. 实验过程

引擎：`blackjack_game.py`。双臂对照，同鞋种子（seeds 1–10），bank 100、注 10，
破产或 400 轮封顶：

- `basic`——gold 策略（硬牌/软牌 × 庄家明牌的完整矩阵，含 double 决策）；
- `dealer_mimic`——朴素玩家：模仿庄家规则（<17 命中、≥17 停牌），从不加倍。

复现命令：

```bash
python3 experiment.py
```

关键过程输出：

```
strategy        rounds  final bank   peak   win%  lose%  bust%
basic            298.5        87.0  236.5  18.9  33.4  16.4
dealer_mimic     144.9         2.0  152.0  16.8  24.7  31.9
```

可视化服务实测（`serve_blackjack.py`）：决策面板展示的请求原文里包含完整的鞋组成
JSON 与爆牌概率（如 "Your hand: 9♠ J♦ = 19 … Probability the next card busts you: 38.3%"），
裁判回答与基本策略表逐条可对照。

## 4. 实验结果说明

### 基本策略让生存时间翻倍

basic 平均存活 298.5 轮 vs dealer_mimic 144.9 轮（×2.06）；final bank 87 vs 2，
peak bank 236.5 vs 152.0。两臂最终都趋向破产——这**必须如此**（21点是负期望游戏，
如果某策略长期盈利说明引擎有 bug），差距完全体现在生存曲线的斜率上。

### 机制：爆牌率减半

basic 的爆牌率 16.4% vs mimic 31.9%，几乎减半。机制清晰：mimic 在"12–16 对庄家
强牌"这些必输局面照搬庄家规则持续要牌，把本可由庄家爆掉的小输变成自己爆掉的大输；
basic 在这些局面选择 stand，把命运交给庄家规则。win% 两臂接近（18.9 vs 16.8）
进一步印证：差距不在赢的能力，而在**输的方式**——这正是基本策略的核心设计
（先止损，后图赢）。

### 对接真实 Jev 的预期

裁判拿到的请求里，爆牌概率、鞋组成、手牌价值全部是 harness 预计算好的——判断者
不需要算术，只需要查表式地对照 instructions 里的策略陈述。真 Jev 的偏离样本
（何时选择偏离基本策略）与最终 bank 曲线的相关，就是这个环境能给出的
"判断质量 → 长期收益"的直接度量。`--judge jev` 零改动可用。

## 5. 结论与后续

1. 引擎经 10 鞋 × 数百轮自对弈无校验失败，赔付与重洗逻辑正确；
2. 基本策略相对朴素策略：生存 ×2.06、爆牌率 ÷1.95——负期望下的策略价值被
   干净地度量出来；
3. 后续：真 Jev 接入后记录每手偏离 gold 的样本，按庄家明牌分桶统计，即可
   生成"Jev 对基本策略的偏离热力图"。

产物：`artifacts/experiment_strategy.json`（双臂全部鞋的轨迹与比率）。
